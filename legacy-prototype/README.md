# Algorithm Visualizer

AI-powered step-by-step algorithm visualizer using Google Gemini.

## Setup (one time)

Make sure you have Node.js installed, then:

```
cd algorithm-visualizer
node server.js
```

Then open your browser to: **http://localhost:3000**

That's it. No npm install needed — uses only built-in Node.js modules.

## Usage

1. Enter your Gemini API key (starts with AIza...)
2. Pick a preset algorithm or describe your own
3. Use the playback controls to step through the execution
4. Read the AI explanation panel on the right
5. Ask questions in the chat box

## Stopping the server

Press `Ctrl+C` in the terminal.
